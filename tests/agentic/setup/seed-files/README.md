# Sample Project

A simple TypeScript server application for testing purposes.

## Getting Started

```bash
bun install
bun run src/main.ts
```

## Structure

- `src/main.ts` — Application entry point
- `src/utils.ts` — Utility functions (date formatting, config parsing)
- `src/types.ts` — TypeScript type definitions
- `src/server.py` — Python server example
- `tests/` — Test files
